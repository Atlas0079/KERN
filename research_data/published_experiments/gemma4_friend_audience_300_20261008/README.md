# Gemma 300 画像好友类别配对单页决策测试

运行日期：2026-10-08；完成时间：19:36（Asia/Shanghai）。
这是统一首次阅读的假设详情页决策测试，不是 KERN 平台传播模拟。
300 固定画像 × 两篇海平面帖子 × 带／不带好友类别，共 1,200 请求，每格独立采样一次。
使用 gemma-4-31B-it，temperature=0.9，max_tokens=1200；随机请求顺序 seed=20261008。
同一角色、同一帖子两版本只有 system 中的好友类别字段不同。完整帖子、零互动计数、空评论与空操作记忆保持相同。
提示词要求私人 reaction 和点赞、评论、转发各自 execute/reason；不执行平台操作。生成好友类别是角色设定，不是已验证的真实关系。

动作可以同时选择，表中动作数量不互斥；不互动表示有效回复未选择任何动作。

| 帖子 | 有效配对 | 均不转发 | 均转发 | 仅不带好友转发 | 仅带好友转发 |
| --- | ---: | ---: | ---: | ---: | ---: |

| 解决方案聚焦 | 300 | 300 | 0 | 0 | 0 |

后果组的 1 对因无效回复未纳入有效配对；无效不是不互动或不转发。
带好友类别没有增加本次样本中的转发数量。每格只有一次模型采样，不能把选择差异独立归因于好友字段，也不能据极少量转发判断研究机制已得到验证。

## 转发理由与无效回复

角色 150 在后果聚焦帖子下两个版本均转发：不带好友时认为这是严肃全球议题，值得让更多朋友看到；带好友时强调报告的紧迫感和提高生态危机认知。解决方案帖子两个版本都认为点赞和评论已经足够表达支持。
角色 024 是唯一转发选择发生变化的有效配对：不带好友时希望让朋友意识到危机；带好友时认为内容沉重，自己心情一般，不想在主页发布令人焦虑的内容。
consequence_agent_045_without_friends_result.json 的模型选择 comment.execute=true，但把评论正文 text 放在 JSON 顶层，而非 decisions.comment.text。既定解析规则将其记为无效；原始响应保留，没有修正、重跑或将它混入有效统计。

## 文件

- enriched_profiles.json：本次使用的全部 300 画像与好友类别。
- manifest.json：当次任务清单与条件说明；source_profiles 保留执行时的本机来源路径，本目录的 enriched_profiles.json 是对应发布副本。
- summary.json：四组最终统计及转发配对计数。
- repost_reason_comparison.json：各角色两版本转发决定与理由，包括仅一个版本有效的记录。
- *_request.json / *_result.json：1,200 份请求及 1,200 份原始响应、解析结果或错误，共 2,400 文件。

模拟和记录都在本机，学校服务器只提供推理 API。临时 Gemma 服务和本机 API 转发已清理。凭据、临时测试脚本、数据库和本机控制文件不在结果包中。
