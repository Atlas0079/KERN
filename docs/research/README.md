# KERN 调研资料

本目录保存为设计和研究决策提供输入的调研材料。此类材料主要由 LLM
辅助检索、归纳和起草，可能包含尚未逐项复核的解释。它们不是 KERN 的
运行时契约，也不用于声明当前实现状态。

采用调研结论前应检查原始来源、发布日期、适用范围和当前代码。已经形成
工程决定的内容应写入 `docs/` 下对应的设计文档或计划文档，不应只保留在
调研材料中。

## 目录

- `social_platform/`：社交传播机制、画像生成和风险信息案例。
- `simulation/`：仿真研究方法与通用验证要求。
- `models/`：模型能力、模型卡和部署调研。
- `related_work/`：KERN 相近项目与文献。
