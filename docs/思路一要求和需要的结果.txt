# 海平面风险叙事传播实验需求

## 研究目的

本实验用动态多智能体仿真补充静态回归分析。异质 Agent 在类微博平台中接收风险科普帖子，并在自己的身份背景、人格、当前页面、公开互动信号和个人有界记忆下逐次决定是否点赞、评论或转发。实验观察不同叙事策略如何通过推荐、曝光、个体决策和关注网络形成随时间变化的传播轨迹。

仿真结果只解释已定义机制下的相对差异，不直接外推为真实平台总体行为。

## 正式实验条件

当前实验只包含两个条件：

1. `sea_level_consequence_focus`：海平面后果聚焦。
2. `sea_level_solution_focus`：海平面解决方案聚焦。

两个条件必须分别独立运行，不能把两篇实验帖子同时投放到同一轮平台中。两轮运行复用同一批 300 个 Agent、同一关注网络、同一活跃调度 seed、同一平台和推荐参数，仅替换实验帖子。正式结果比较两条累计转发曲线。

tick 不对应分钟、小时或自然日，只表示一次离散的传播机会轮次。Agent 的完整访问计划在运行前由活动调度模型生成，两实验条件复用同一份计划；Agent 打开平台后才由推荐算法生成页面，并对实际曝光内容作出互动决策。

## 必需输出

### Method：Agent 决策流程

清楚说明身份画像、人格、活跃概率、关注网络、推荐机制、页面曝光、LLM 决策、EffectBundle 提交和个人记忆之间的顺序与边界。评审应能理解 Agent 看见了什么、没有看见什么，以及每次平台行为为什么发生。

### Result：动态传播曲线

输出一张双线折线图：

- X 轴：传播轮次（tick），不换算为现实小时；
- Y 轴：累计转发人数或累计转发数；
- 曲线一：海平面后果聚焦；
- 曲线二：海平面解决方案聚焦。

同时保留每 tick 新增曝光、首次曝光、点赞、评论、转发、传播来源和级联深度等原始事实，便于解释曲线差异。

除累计转发曲线外，同时报告每次曝光后的转发率。正式比较使用固定且相同的最大传播轮数，不能因为某个条件较早停止增长就只截取该条件的曲线。
